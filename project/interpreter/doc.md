# GQL Interpreter and Type Checker
Для реализации интерпретатора языка запросов к графам использовался тензорный алгоритм,
так как в задачах этого курса он показал хорошую производительность, в отличие от, например, матричного
алгоритма.

## Решение

### Окружение и управление переменными

Класс ```Env``` представляет окружение для хранения переменных и их значений в разных областях видимости.
- ```__init__(self)```: Инициализирует окружение со списком областей видимости, начиная с глобальной области.
- ```add(self, var: str, val)```: Добавляет переменную var со значением val в текущую область видимости.
- ```next_scope(self)```: Создает новую область видимости, добавляя пустой словарь в список.
- ```remove_last(self)```: Удаляет последнюю область видимости. Если попытка удаления касается глобальной области, возбуждается исключение ```RemoveGlobalScopeException```.
- ```find(self, name: str)```: Ищет переменную name во всех областях видимости начиная с последней. Если переменная не найдена, выбрасывается исключение ```VariableNotFoundException```.

Класс с таким же названием присутствует и в системе проверки типов. Здесь реализован словарь, который хранит соответствие имен переменных их типам.

### Ленивое вычисление выражений

Класс ```LazyNFA``` обеспечивает ленивое вычисление NFA для поддержки forward references и взаимной рекурсии в регулярных выражениях.

**Основные методы:**
- ```__init__(self, ctx, name)```: Инициализирует ленивое вычисление с контекстом выражения и именем переменной.
- ```get_value(self, visitor)```: Вычисляет NFA при первом обращении. При рекурсивном вызове (когда переменная ссылается сама на себя) возвращает символ для построения RecursiveAutomaton.

**Принцип работы:**
- При определении регулярного выражения ```let x = expr``` создается ```LazyNFA```, который хранит контекст выражения, но не вычисляет его немедленно.
- Вычисление происходит только при первом обращении к переменной через ```get_value()```.
- Флаг ```_computing``` отслеживает рекурсивные обращения: если переменная запрашивается во время своего же вычисления, возвращается символ-placeholder.
- Это позволяет корректно обрабатывать:
  - **Forward references**: ```let q = "a" . p; let p = "b"```
  - **Взаимную рекурсию**: ```let s = a | "b"; let a = "a" . b; let b = s . "b"```
  - **Самостоятельную рекурсию**: ```let p = "a" . p . "b" | "c"```

### Проверка типов

Проверка соответствующих типов выражений и операций реализована с помощью класса ```GQLInfer```. В этом классе происходит
обход дерева разбора согласно паттерну _Visitor_, который позволяет обрабатывать каждый узел дерева, выполняя
соответствующие действия и проверки.

**Ключевые особенности типизации:**
- Поле ```current_binding``` отслеживает текущую определяемую переменную для корректного определения рекурсии.
- Метод ```_handle_var``` различает три случая использования переменной:
  - Рекурсивное использование (переменная в своем определении) → тип ```RSM```
  - Неопределенная переменная (символ грамматики) → тип ```FA```
  - Ранее определенная переменная → используется ее тип
- Запрещено пересечение (```&```) двух ```RSM```, так как пересечение контекстно-свободных языков не является контекстно-свободным.

Каждый метод visit*N* обрабатывает конкретный узел дерева, который соответствует определенной грамматической конструкции языка GQL.

### Выполнение запросов

Класс ```MyVisitor``` реализует интерпретатор языка GQL, обходя дерево разбора и выполняя соответствующие операции.

**Обработка регулярных выражений:**
- Метод ```visitBind``` различает регулярные выражения и другие типы значений:
  - Для регулярных выражений создается ```LazyNFA```
  - Для других типов (числа, строки, множества, графы) значение вычисляется немедленно
- Метод ```_handle_var``` при обращении к переменной:
  - Проверяет, является ли значение ```LazyNFA```
  - При необходимости вычисляет ```LazyNFA``` через ```get_value()```
  - Для неопределенных переменных создает терминальный символ

**Построение RecursiveAutomaton (RSM):**
- Метод ```visitSelect``` обрабатывает SELECT-запросы:
  1. Собирает все определенные NFA из окружения
  2. Вычисляет все ```LazyNFA``` для получения фактических NFA с корректными рекурсивными ссылками
  3. Вызывает ```build_rsm()``` для построения RecursiveAutomaton
  4. Использует ```tensor_based_cfpq()``` для выполнения запроса с контекстно-свободными ограничениями

**Функция ```build_rsm```** (в ```utils.py```):
- Принимает основной NFA и словарь подстановок (имя → NFA)
- Создает Box для каждого NFA с соответствующей меткой (символом)
- Возвращает RecursiveAutomaton с заданной начальной меткой
